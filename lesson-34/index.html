Pre-test · warm-up

Warm-up: Shadowing

Shadowing — today's focus

Build a Sentence rewards structure, not vocabulary. Find the subject first, then the main verb, then attach the connector. Small function words and punctuation decide the score. Do the easy items quickly, and leave the hard one for the end.
140 WPM

Section 3 · Writing — timed

Writing

Error sort — 3 minutes

Name the problem in each line: word order · connector · function word.
  1. “The experiment failed because was damaged the sensor.”
  2. “The study not only changed policy, it also saved money.”
  3. “Although was expensive, the equipment proved reliable.”
Show answers👁️
1 word order · 2 connector (not only … but also) · 3 function word (missing subject after although)

BUILD — 4 min 30 s (45 s per item)

Put the words in order. One sentence each.
04:30

1. because / the experiment / failed / the sensor / was damaged

Show answer👁️
The experiment failed because the sensor was damaged.

2. although / was expensive / the equipment / it / proved reliable

Show answer👁️

3. the student / who / won the prize / studied / at night

Show answer👁️
The student who won the prize studied at night.

4. not only / the study / but also / changed policy / it / saved money

Show answer👁️
The study not only changed policy but also saved money.

5. if / the results / are confirmed / the team / will publish

Show answer👁️
If the results are confirmed, the team will publish.

6. the report / that / was rejected / contained / useful data

Show answer👁️
The report that was rejected contained useful data.
  • Subject before verb
  • Connector at the correct end
  • Small words kept
  • Punctuation checked
